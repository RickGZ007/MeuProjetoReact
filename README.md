# 🚀 Meu Projeto React + Firebase

Aplicação web desenvolvida em **React** com sistema completo de **Cadastro, Login e Área Principal**, utilizando autenticação real com **Firebase Authentication** e armazenamento de dados no **Firestore**.

## 🌐 Acesso Online

🔗 Projeto publicado:
https://meuprojetoreact.netlify.app/

---

## 📌 Funcionalidades

### ✅ Página de Cadastro

* Cadastro de usuário com:

  * Nome
  * Sobrenome
  * E-mail
  * Senha
  * Data de nascimento

* Criação de conta no Firebase Authentication

* Salvamento dos dados no Firestore

* UID do usuário armazenado no banco

---

### ✅ Página de Login

* Login com e-mail e senha
* Validação real via Firebase
* Mensagem de erro para dados inválidos
* Nova tentativa de login
* Redirecionamento para área principal

---

### ✅ Página Principal

Exibe dados do usuário autenticado:

* Nome
* Sobrenome
* Data de nascimento
* E-mail

Além disso:

* Botão Sair (Logout)

---

## 🛠️ Tecnologias Utilizadas

* React
* React Router DOM
* Firebase Authentication
* Firestore Database
* CSS Responsivo
* Netlify (Deploy)
